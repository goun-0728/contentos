# 리뷰 클레임 수집기

네이버 스마트스토어 상품 페이지의 공개 리뷰를 크롬 확장프로그램으로 수집하여 로컬 웹앱에 저장합니다.

---

## 구조

```
review-collector/
  app/
    server.mjs        ← 로컬 웹앱 서버 (Node.js)
  extension/
    manifest.json
    popup.html
    popup.js
    content.js
  reviews.json        ← 수집 데이터 (자동 생성)
  reviews.csv         ← CSV 내보내기 (자동 생성)
```

---

## 1. 로컬 웹앱 실행

```bash
node review-collector/app/server.mjs
```

브라우저에서 http://localhost:4174 접속

---

## 2. 크롬 확장프로그램 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 토글 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 버튼 클릭
4. `review-collector/extension` 폴더 선택
5. **리뷰 클레임 수집기** 확장이 목록에 표시되면 완료

---

## 3. 리뷰 수집 방법

1. 로컬 웹앱 서버를 실행합니다 (`node review-collector/app/server.mjs`)
2. 크롬에서 네이버 스마트스토어 상품 페이지를 엽니다
3. 상품 페이지에서 **리뷰 탭을 클릭**하여 리뷰가 화면에 보이도록 합니다
4. 크롬 툴바의 확장프로그램 아이콘을 클릭합니다
5. **품목명**, **업체명**을 입력합니다
6. 필요하면 **클레임 후보만 수집** 체크박스를 켭니다
7. **현재 페이지 리뷰 수집** 버튼을 누릅니다
8. http://localhost:4174 에서 수집 결과를 확인하고 CSV로 다운로드합니다

---

## 안전 범위

- 사용자가 직접 열어서 보고 있는 페이지의 공개 리뷰 텍스트만 수집합니다
- 로그인 우회, 캡차 우회, 자동 페이지 이동 기능은 없습니다
- 중복 리뷰는 자동으로 제외합니다
